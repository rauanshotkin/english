# Lumi — английский между строк

React SPA для изучения английского через чтение. Интерфейс на русском, перевод по умолчанию на **қазақша**, с переключением на русский. Аккаунт не нужен.

## Запуск

Нужен Node.js **24.5+**: сервер использует встроенную SQLite. Все команды выполняются из `/workspace/english`.

```bash
npm ci --cache /workspace/.npm-cache
npm run dev
```

`npm run dev` запускает Vite на порту **5173** и API на **3001**. Vite проксирует `/api` к API; оба процесса необходимы для серверного перевода и счётчика. Шрифты, иллюстрации и учебный словарь включены в проект, без внешних CDN.

Для production:

```bash
npm run build
npm start
```

Express обслуживает собранную SPA и API на одном порту; `PORT` меняет порт (по умолчанию 3001). При размещении за HTTPS-прокси задайте `PUBLIC_ORIGIN=https://ваш-домен`, чтобы проверка источника запросов и Secure cookie соответствовали внешнему адресу. Каталог `.data/` должен храниться на постоянном диске: в нём находится SQLite счётчика.

## GitHub Pages

Публичная статическая версия рассчитана на `https://rauanshotkin.github.io/english/`. Сборка для Pages:

```bash
npm run build:pages
```

Режим Pages задаёт путь `/english/` для ресурсов и отключает серверные запросы к счётчику. Альтернативная команда для Linux: `GITHUB_PAGES=true npm run build`. GitHub Pages не запускает Node.js или SQLite, поэтому в этой версии **нет счётчика уникальных посетителей и согласия на аналитику**. Внизу страницы показано «Без отслеживания». Согласие на сохранение прогресса и словаря в cookies, импорт текста, озвучивание и все локальные переводы работают.

Для незнакомых слов и фрагментов браузер обращается к MyMemory напрямую только по действию читателя. Запрос содержит выбранный текст и языковую пару, без cookies приложения. Доступность зависит от сети, поддержки запросов из браузера и бесплатной квоты сервиса; ошибки показаны в панели перевода. Локальные переводы учебных глав доступны независимо от внешнего сервиса. Обычная сборка без флага сохраняет серверный режим для собственного хостинга.

Публикацию выполняет workflow `.github/workflows/pages.yml` при отправке изменений в `main`; в настройках репозитория **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**.

## Что работает

- Библиотека с поиском и фильтрами; чтение с содержанием и навигацией по главам.
- Нажатие на слово показывает перевод, произношение и перевод предложения, в котором оно встречается.
- Выделение фрагмента открывает перевод. Все слова учебных глав, 90 предложений и 72 выражения доступны локально; другие фрагменты переводятся через MyMemory.
- Личный словарь и карточки для повторения. Слово можно удалить или послушать.
- Озвучивание глав через Web Speech API с выбором скорости. Доступность английских голосов зависит от браузера и устройства.
- Светлая, бумажная и тёмная темы; чтение по умолчанию 22 px с настройкой от 18 до 34 px. Основной текст интерфейса — 16 px, кнопки не меньше 44×44 px. На телефонах карточки перестраиваются в одну колонку, а перевод открывается над крупной нижней навигацией.
- Импорт собственного `.txt` UTF-8 до 1 МБ. Текст обрабатывается в браузере и доступен до перезагрузки; повторный импорт того же файла может восстановить последнюю главу, если разрешено сохранение прогресса.
- Управление с клавиатуры: Tab до текста, стрелки между словами, Enter для перевода. Фокус переходит в панель перевода и возвращается к слову при закрытии.

## Книга

Встроенный материал «The Little Prince» — **8 коротких авторских учебных пересказов**, а не полный текст романа или его оригинальный перевод. Это явно указано в библиотеке и ридере. Иллюстрация создана для приложения в SVG. Полный текст пользователь может открыть из своего файла.

Переводы служат учебными подсказками: английские слова могут иметь несколько значений. Контекст предложения помогает выбрать смысл.

## Cookies и данные

Первый визит предлагает равноправные варианты: необходимые cookies, настройку или все категории. Необязательные категории изначально выключены. Политика и отзыв согласия доступны через «Cookies и приватность» внизу страницы.

| Данные                                      | Где хранятся               | Условие              | Срок                         |
| ------------------------------------------- | -------------------------- | -------------------- | ---------------------------- |
| Выбор cookies                               | `lumi_consent`             | Необходимый          | 180 дней                     |
| Глава, завершённые главы, шрифт, тема, язык | `lumi_progress`            | Согласие на прогресс | 180 дней                     |
| Сохранённые слова и переводы                | `lumi_words`               | Согласие на прогресс | 180 дней                     |
| Случайный идентификатор посетителя          | `reader_visitor`, HttpOnly | Согласие на счётчик  | 365 дней                     |
| Хеш идентификатора и срок удаления          | SQLite на сервере          | Согласие на счётчик  | 365 дней с последнего визита |

Словарь ограничен 25 записями и размером cookie; при заполнении старые записи удаляются. Без согласия настройки и слова работают в памяти текущей сессии. Файлы книг целиком не записываются в cookies и не загружаются на сервер; при запросе перевода отправляется только выбранный фрагмент.

Счётчик измеряет **уникальные согласившиеся браузеры**, а не точное число людей. Приложение не использует IP-адреса, аккаунты или отпечатки устройств для идентификации. Повторный визит с тем же cookie не увеличивает число; отзыв согласия удаляет запись и cookie. При недоступном API удаление повторяется при следующем открытии сайта.

Неизвестный словарю выбранный текст отправляется MyMemory по явному запросу пользователя. API бесплатный, с ограничением квоты; ошибки и недоступность показаны в интерфейсе. Нужен HTTPS-доступ к **api.mymemory.translated.net**. Для серверного режима `ENABLE_EXTERNAL_TRANSLATION=false` отключает внешние запросы. В облачной среде внешние запросы могут блокироваться сетевой политикой; это не влияет на локальные переводы.

## Проверки

```bash
npm run build
npm test
# При запущенном npm run dev:
npm run test:e2e
```

Серверные тесты проверяют согласие, отсутствие отслеживания до него, дедупликацию, срок хранения, удаление, сохранение SQLite между перезапусками, проверку источника и языков, перевод и обработку сетевых ошибок. Браузерная smoke-проверка использует Playwright и системный Chromium; можно указать `CHROMIUM_EXECUTABLE` и `BASE_URL`. Если Chromium отсутствует, установите браузер командой `npx playwright install chromium`.

Ручная браузерная проверка выполнена для десктопа и ширин 320/390 px: перевод, сохранение после перезагрузки, словарь, карточки, импорт, настройки cookies и отзыв согласия. Проверены клавиатура, фокус диалога и контраст основных экранов.

## Структура

- `src/App.tsx` — библиотека, ридер и разделы обучения.
- `src/components/` — иллюстрация и диалог согласия.
- `src/lib/storage.ts` — ограниченное cookie-хранилище с согласием.
- `src/data/` — главы и локальные переводы.
- `server/` — API, SQLite и резервный перевод MyMemory.

Новые разделы и книги можно добавлять через структуру глав и навигацию, сохраняя единый ридер.
